# Troubleshooting

## Upload fails

Folder name inside the zip is not `bun`. Rename it. Zip again. See [Install](INSTALL.md#zip-rule).

## BUN does not start

- Customize > Skills. Is BUN on?
- Start a new chat.
- Ask plainly: `Write a LinkedIn post`.

## BUN skips the start question

You already answered part of it. BUN skips what you said. Missing a piece? Say "ask me the start question".

## Post has `[add number]`

You did not give that detail. BUN never invents one. Send the real number. Or cut the line.

## Post uses numbered lists

BUN uses bullets by default. Numbers appear only when you ask. If you did not ask, say "bullets only".

## Post has a link or hashtag

Links go in the first comment. Hashtags are off. Say "remove it". BUN changes only that line.

## Too long or too short

Target is 200-400 words. Say "shorter" or "add detail". BUN shows only the changed lines.

## No idea and search does not work

Idea search needs web search. No search? Pick "I have an idea". Share one real story or number.

## Hooks all look the same

BUN gives 3 hooks, 3 types. Want others? Name a goal: comments, reposts, likes, or saves. Hook types change with the goal.

## Post sounds like AI

Send the lines that bother you. Say what feels off. BUN rewrites those lines. Hooks may use patterns the humanizer cuts in the body.

## Chat gets long and BUN forgets

Start a new chat. Paste your niche, audience, and goal. BUN starts fresh.
