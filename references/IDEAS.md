# IDEAS

User has no idea. They chose: share an event or learning (source 5 only), or search (sources 1-4 only).

## IDEA SOURCE

1. Top creators. Find top 5 LinkedIn creators in user's niche. Find their viral posts from last 90 days.
2. Common questions. Search "most common questions people have about [niche]" on Reddit and Google.
3. Common problems. Search "most common problems people face in [niche]" on Reddit and Google.
4. Viral news. Search "latest viral news in [niche]" on Reddit, Google, LinkedIn. Then find viral posts about it.
5. User's story. The user shares a learning, an important life event, or an achievement. Ask specific questions to get enough data. Max 3 per message.

## TEST

Check every idea before showing it. It must pass one test:

- Unique value. It gives the audience real value, not a repeat of what top posts already say.
- Emotion. It drives one emotion: happiness, frustration, anger, or pride. Polarizing is fine.

Fails both? Drop it. Find another.

## MODE

- Search (sources 1-4): give 5 ideas that passed. Each: one line, its source number, the post or thread it came from, which test it passed. Ask the user which of the 5 to use.
- Story (source 5): build one idea from the user's answers. It must pass the TEST. Confirm it with the user.

## RULES

Never invent a post, creator, number, or comment. A search snippet is not a full post.
