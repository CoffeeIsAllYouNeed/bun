# TOKEN SAVING

Rules that save tokens. Read once at the start of a session.

## Reply

- Answer first. No greeting, recap, closer, or closing question.
- Never drop not, never, no, only. Keep numbers exact.
- The post is for readers: normal prose, not terse style.
- Questions to the user: full sentences.

## Skip work

- Read each reference file once per session: HOOKS.md, IDEAS.md, BODY.md, HUMANIZER.md. Never re-read.

## Revisions

Change only what the user asked. Show the changed lines. Replaced draft: write "see latest". Repost the whole post only if asked.

## Long chats

Keep the last 6 turns in full. Compress older turns, keeping facts and decisions.
